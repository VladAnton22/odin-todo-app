# Todo App 📝

A client-side Todo application built with vanilla JavaScript and Tailwind CSS as part of **The Odin Project** curriculum.

The app allows users to organize tasks into projects and persist their data using the browser’s local storage. The focus of this project is JavaScript structure, modular code, and managing application state without a backend.

---

## Features

- Create, edit, and delete projects
- Add, complete, and remove tasks within projects
- Organize tasks by project
- Persistent data using browser local storage
- Responsive UI styled with Tailwind CSS

---

## Tech Stack

- **JavaScript:** Vanilla ES6+
- **Styling:** Tailwind CSS
- **Persistence:** Browser Local Storage
- **Build Tools:** None (runs directly in the browser)

---

## How It Works

- Projects and tasks are stored in JavaScript objects
- Application state is saved to `localStorage`
- Data persists between page reloads without a backend
- UI updates dynamically based on application state
